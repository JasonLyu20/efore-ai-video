# 第一期视频制作前期方案总结

Efore　2026年11月5日

第一期按五人团队自行制作、暂无成熟后期能力、不依赖外包安排。采用“AI 短镜头＋基础剪辑”，准确产品照片或已有视频作为替代。先用现有素材完成一条 15 秒试剪，通过后再投入生成和整片制作。

本期产品为 IBUE48100、IBUE48200、ESmart-Li48160，保留一条 60–90 秒主片、三条各 15 秒短片及约定的语言和声音版本。目标是产品准确、表达清楚、方便修改。华为的暗色背景、产品特写和慢速运动可以借鉴，暂不以同等成色作为交付承诺。

## 前期工作结论

| 已完成工作 | 主要结论 | 对本期的影响 |
| --- | --- | --- |
| 需求整理 | 三款具体产品，需静音可理解并适合展会播放 | 先确认卖点、版本和产品资料，不扩大产品范围 |
| AI 工具调研及评分 | 已形成候选和价格参考，尚无本期产品实测 | 分数用于挑候选，不能直接当采购结论 |
| 竞品视频调研 | 已整理 6 条官方产品或工业视频 | 参考镜头和信息组织，不照搬复杂结构动画 |
| 制作可行性分析 | 团队当前缺少后期能力，外包不作为前提 | 先验证基础剪辑，再决定生成投入和整片安排 |

现有调研可以支持试制，但尚未证明团队能按期完成整片。华为视频的实际制作工具未经确认，不以其画面作为全 AI 能准确还原本期产品的证据。

## 制作方案

| 方式 | 本期安排 |
| --- | --- |
| 全 AI 动态镜头 | 可以测试。结构错误的镜头不用，不能依赖大量后期修补 |
| 专业实拍与复杂合成 | 暂不安排；已有准确视频可以直接使用 |
| AI 短镜头加基础剪辑 | 优先试制，固定版式、少量运动、直接切换 |
| 准确照片或已有渲染图 | 作为稳定替代，配轻微推近或固定画面 |

AI 主要尝试产品整体、可核对的细节及独立环境镜头。型号、Logo、参数和字幕在剪辑层添加。环境与产品直接剪接，不强行做动态抠像、跟踪或光线匹配；开盖、装配、爆炸图和复杂内部动画不从零制作。

## 五人分工

| 角色 | 主要工作 |
| --- | --- |
| 项目与产品 | 确认需求和技术信息，统一评审意见，决定继续或调整 |
| 文案与分镜 | 安排展示顺序，压缩文字，准备中英文和统一版式 |
| 素材与核对 | 整理原图、Logo、已有视频及授权，检查结构和型号 |
| AI 工具 | 核对实际账户和价格，试生成并记录全部尝试 |
| 基础剪辑学习 | 学习导入、裁切、拼接、文字、简单音频、修改和导出 |

最后一个角色是需要验证的学习任务，不能按熟练后期人员估算产能。启动时填写实际成员和每天可投入时间，其他成员承担素材整理和核对，减少剪辑人员的杂项工作。

## 先做一条能修改的短片

先选资料最完整的一款，用已有照片、Logo 或视频完成约 15 秒试剪，不新增会员、设备、插件或外包采购。第一轮只验证基本操作，可以只讲一个核准卖点。

试剪应能顺序播放、修改字幕、替换画面，并在工程关闭后重新打开。输出时记录分辨率、帧率、编码及水印，在目标设备试播；缺少设备或编码未验证时，要保留为待解决问题。

建议给首轮 5 个工作日作为学习和复盘窗口，从资料到位、负责人能够投入时开始。这是检查进展的时间点，不是五天一定掌握的保证。若仍无法完成，先改用固定图片和直接切换，或延长学习；不提前批量生成，也不自动转外包。

试剪通过后，先用一个已有可用模型生成整体慢推、局部细节和独立环境三类镜头，每类最多两次。确需比较时，再试第二个模型，首款累计最多 12 次。把合格片段放回同一工程，能完成剪辑和修改后，再覆盖其余两款。

每条采用的 AI 动态片段至少连续三秒可用。相同结构错误连续出现两次，就调整参考或改用原图。照片动效单独记录，不能计作模型动态成功。正式短片仍须满足产品定位和三个卖点等原需求。

## 费用与后续安排

| 阶段 | 当前费用安排 |
| --- | --- |
| 基础试剪 | 新增采购 0 元，使用已有素材和工具权益 |
| 首款生成 | 一个模型最多 6 次起步；必要对照累计最多 12 次，建议耗用上限 300 元 |
| 三款验证 | 累计最多 36 次、建议耗用上限 800 元，包含首款费用 |
| 正式制作 | 依据三款验证、逐镜头分镜及实际费用重新估算 |

以上是待确认上限，尚未发生付费调用。次数或费用任一先到即停止。300 元已经包含在 800 元内，充值门槛、实际耗用和余额分开记录；若最低付款超出当前资金条件，不强行购买。

沿用原价格快照，Seedance 2.0 与 Kling 3.0 Omni 各做 6 次的算例为 241.92 元，三款两模型共 36 次为 725.76 元。该算例对应原指定的 5 秒 4K API 入口，不是网页会员报价；换入口、版本或规格时必须重算。优先使用团队已有且能操作的账户，不为了价格表单独建设 API 工作流。

旧版 18 个工作日、112–168 人时、5,279.87 元基准预算及 6,000 元采购额度均不再作为当前执行基准。内部人员的学习和操作时间用于排期，暂不折算人工费用。

三款产品均有可用展示方式后，再确定主片精确时长、短片复用、语言与声音版本，并核算各成员剩余工作。正式排期必须包含两轮修改、全版本导出和播放检查，不能用总人时简单除以五人得到交期。

## 交付与继续条件

正式交付保留原定主片、三条短片、约定语言和声音版本、编码及源工程。产品和参数须准确，按需求核验分辨率、16:9、30fps；字幕至少停留三秒，关键信息避开边缘 10%，在目标电视约五米处可读，并连续循环播放三次。

只有团队能修改、导出和播放，且三款必要镜头都有准确素材，才进入整片制作。否则保留已经完成的脚本与素材，调整学习时间或与需求方确认阶段交付，不把测试片当正式成片，也不擅自降低产品准确性和交付规格。
