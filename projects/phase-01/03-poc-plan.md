# 第一期试剪与生成验证方案

更新日期：2026-11-05。团队暂按无人具备成熟后期能力、第一期不依赖外包安排。尚未执行本方案、购买套餐或生成付费样片。

## 1 先试剪 再花生成费用

第一步用已有产品照片、Logo 和视频做一条 15 秒测试片，不新增采购。只练习导入、裁切、拼接、固定文字、简单音频和导出；不安排抠像、跟踪、复杂调色或三维制作。

首轮给 5 个工作日作为学习与复盘窗口。由指定成员实际完成，再由另一名成员核对型号和画面。记录每次操作耗时、卡住的步骤和软件要求。

| 检查 | 通过标准 |
| --- | --- |
| 时间线 | 约 15 秒，能顺序播放，无意外黑帧或拉伸 |
| 产品与文字 | 一款产品及一项已核准卖点准确，文字独立可改 |
| 修改 | 替换一张图片、修改一句字幕后可再次输出 |
| 工程 | 关闭后可重新打开，素材可找到 |
| 声音 | 能输出静音版；有已授权音频时完成添加与音量练习 |
| 文件与设备 | 记录实际分辨率、30fps、编码和水印；在目标设备试播 |

缺少目标设备或编码未验证时，明确列为缺口，不当作已具备正式交付能力。试剪通过后才进入付费生成；未通过时先简化操作或延长学习。测试片允许只讲一项卖点，正式短片仍按 01 的定位和三个卖点要求执行。

## 2 首款生成验证

选资料最完整的一款。Seedance 2.0 与 Kling 3.0 Omni 作为候选，先用团队已有且能实际操作的一个入口；不是要求先购买两个套餐或开发 API 工具。

统一用已核准参考图、相同风格和约 5 秒输出测试以下镜头。文字、Logo 和参数在剪辑层添加，不要求模型生成准确文字。

| 用例 | 内容 | 每模型次数 | 主要检查 |
| --- | --- | ---: | --- |
| T01 | 产品正面轻微推近 | 最多 2 | 轮廓、比例、面板与接口稳定 |
| T02 | 有清晰参考的局部细节轻微运动 | 最多 2 | 已知结构准确，不补造未知表面 |
| T03 | 独立应用或科技环境，不嵌入产品 | 最多 2 | 可与产品镜头直接剪接，风格和应用场景合适 |

首个模型最多 6 次。仅当有明确待解决问题或比较需要时，再启用第二个模型的最多 6 次；首款合计最多 12 次，建议耗用上限 300 元，次数与费用任一先到即停止。上限待确认，不能理解为已获采购授权。

所有任务按实际计费记录。第 2 次名额可用于有明确改动的重试或修订；一旦改变条件，就不能把两次当作同条件重复样本。付费编辑、其他时长或视频输入须先重算，不能自动套用普通图生视频价格。

## 3 把生成结果放回试剪工程

把合格镜头替换进第一步的工程，做成一条约 15 秒单品验证片。每个采用的 AI 动态片段至少连续 3 秒可用；停帧和原图动效单独记录，不计作模型动态成功。

正式单品短片可参考下列结构，具体文字仍须做 5 米可读性检查：

| 时间 | 内容 |
| --- | --- |
| 0–3 秒 | 产品名称与一句定位 |
| 3–6 秒 | 第一个核准卖点，配整体镜头 |
| 6–9 秒 | 第二个核准卖点，配细节或准确原图 |
| 9–12 秒 | 第三个核准卖点，配对应画面 |
| 12–15 秒 | 产品与品牌收尾，安排循环衔接 |

如果文字太长或切换不清楚，应缩短文案或重新分配镜头。三个卖点不因简化制作而自动删除。应用场景不得暗示未经确认的安装或性能。

用同一工程完成一次字幕修改和一次画面替换。第一期可以通过替换镜头解决修改，不把掌握生成式视频编辑设为前提。若必须整体重绘产品才改得动，优先调整分镜或使用准确原图。

## 4 单品通过后再覆盖三款

按已验证的方法处理其余两个型号。每款的接口、外观和必要细节分别核验，不能从第一款的成功外推到全部产品。

| 情形 | 总调用数量 |
| --- | ---: |
| 三款均只验证一个模型 | 3 款 × 3 类 × 2 次，最多 18 次 |
| 三款确需两个模型对照 | 3 款 × 3 类 × 2 次 × 2 模型，最多 36 次 |

三款验证建议累计耗用上限 **800 元，包含首款的 300 元上限**。不另加一轮 24 次规格复核，不默认追加 Vidu，也不要求花完额度。新增模型只有在明确指出未解决镜头、调用数和费用后再安排。

实际入口若最低充值超过当前可用额度，先使用已有权益或调整试验，不把“消耗低于上限”当作可以超额充值的理由。

## 5 记录和判断

先检查产品外形、接口、面板、型号及参数。关键结构错误不因画面好看而放行；无需后期修补即可合格的镜头优先采用。

| 记录项 | 方法 |
| --- | --- |
| 素材结果 | 保存所有尝试，分别标记直接可用、基础剪辑可用、不可用 |
| 合格秒数 | 记录连续可用区间，同一素材在短片或语言版中复用只计一次 |
| 费用 | 生成、必要工具分开，记录实扣和退款；充值余额单列 |
| 人时 | 学习、操作、核验、简单剪辑和修改分别记录，不折算人工费用 |
| 等待 | 排队、生成、导出、评审等待单列 |
| 可修改性 | 能改字、换镜头、重新导出，工程不依赖未具备的插件或技术 |
| 设备表现 | 目标规格与电视播放结果，未测项明确列出 |

单位可用素材费用＝全部尝试的净生成费及必要后处理工具费用 ÷ 去重后的合格动态秒数。分母为零记“无可用产出”。产品和环境分别计算；照片动效不纳入 AI 动态合格率。若共享工具已单列，不再按每秒重复加总。

同一结构错误连续两次出现，停止相同条件重试。可缩小运动、换清晰参考，或改用原图及已有准确视频；不安排外包兜底。

## 6 退出产物

完成一款 15 秒工程、三款产品的可用镜头或替代方式、缺陷及费用记录、实际人时、账户和输出参数、后续预算与排期建议。

只有三款产品的必要展示均有可行方式，且团队能修改、输出和播放，才进入整片制作。未通过则保留脚本和素材成果，调整学习窗口或与需求方确认新的阶段交付，不把“已生成视频”写成“成片能力已验证”。

小样本只支持本期下一批决策，不是模型长期成功率。费用算例与原预算的关系见[04 预算](04-budget-method.md)。
