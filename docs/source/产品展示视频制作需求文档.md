为参加行业展会及展厅日常播放，制作一条 60–90 秒产品展示主片（3 个单品串联）及 3 条 15 秒单品短视频。展台为电视 16:9 横屏播放，分辨率不低于 2K、按 4K 交付，静音循环可看，中英文字幕（优先制作英文版，最终考虑分开两版）。建议总工期 14 个工作日。

1. 项目背景

为参加行业展会及展厅日常播放，制作一支产品展示视频，用于吸引到访客户、快速传达产品线价值。风格对标外企高端产品片（如华为数字能源、ABB、Vertiv、Schneider 的展会循环片）。

2. 本期范围（第一期）

产品数量：3 个单品（具体产品：IBUE48100, IBUE48200, ESmart-Li48160）

交付形式：一条 60–90 秒主片（产品串联），另剪辑 3 条 15 秒单品短视频用于展位轮播/社媒

后续第二期再扩展至全产品线

3. 硬性规格（验收必备）

| 项目 | 要求 |
| --- | --- |
| 播放载体 | 展台电视，16:9 横屏 |
| 分辨率 | 不低于 2K（2560×1440），建议按 4K（3840×2160）制作，30fps |
| 时长 | 主片 60–90s；单品短视频 15s ×3 |
| 循环 | 首尾帧一致，支持展厅无缝循环播放 |
| 声音 | 主片静音可看（字幕驱动叙事）；另交付一条带配音版本（中英各一）用于官网 |
| 字幕 | 英文/中文，字号保证 5 米距离可读 |
| 格式 | MP4（H.265 优先、H.264 兜底），高码率；交付前确认大屏播放器规格 |
| 安全区 | 关键信息避开画面边缘 10%，防止大屏裁切 |

4. 风格要求

基调：深蓝黑底（参考 #0A1428），点缀品牌色/能源青蓝色，参考Efore Logo，全片色彩不超过 3 种

字体（可酌情更改）：英文 Montserrat 或 Inter；中文思源黑体 / HarmonyOS Sans；细字重、大字距

运镜：慢速环绕、推近；产品加线框光效与能量粒子动效；节奏克制，拒绝特效堆砌

转场：光效擦除或淡入淡出，一段一信息，字幕停留 ≥3 秒

参考感觉：Apple 产品页的克制 + 能源行业大片的科技感

5. 内容结构（主片 60–90 秒分镜骨架）

| 时间 | 段落 | 内容 |
| --- | --- | --- |
| 0–8s | 品牌开场 | Logo + 定位语（"Energy For Everyone"） |
| 8–15s | 产品线总览 | 三大产品线一屏排开，引出本期 3 个单品 |
| 15–55s | 单品展示（核心） | 每个单品约 12–15s：环绕展示 + 3 个卖点关键词浮现 |
| 55–70s | 应用场景 | 通信基站 / 数据中心 / 工商业园区，产品嵌入真实场景 |
| 70–80s | 信任背书 | 认证图标（CE/UL/TÜV 等）+ 部署数据 |
| 80–90s | 品牌收尾 | Logo 定版 + 联系方式，末帧=首帧实现循环 |

单品展示段要求：

机柜类产品：环绕运镜，可加入开柜/内部结构展示

电池类产品：能量流动画展示卖点

每个单品的信息结构统一：产品名 → 一句定位 → 3 个核心卖点

6. 排期与交付节奏（建议 14 个工作日）

| 阶段 | 工作日 | 产出 |
| --- | --- | --- |
| P1 脚本分镜 | D1–D2 | 方案；逐秒分镜脚本 + 字幕文案 |
| P2 素材准备 | D3–D4 | 产品图整理、场景素材小样 |
| P3 生成与粗剪 | D5–D9 | 60–90s 粗剪版（720p 预览） |
| P4 修改一 | D10–D11 | 精修版（含动效、字幕定稿） |
| P5 修改二 + 终版 | D12–D13 | 4K 终版 + 3 条 15s 单品片 + 配音版 |
| 交付 | D14 | 全部成片 + 源工程文件 + 授权证明 |

7. 验收标准

规格达标：分辨率不低于 2K（按 4K 交付）、30fps、时长、格式、首尾帧一致

静音播放时仅凭画面+字幕即可完整理解内容

产品外观与官方图一致，无 AI 生成导致的结构变形（风机位、走线孔、铭牌逐项核对）

风格符合第 4 节要求，色彩、字体统一
