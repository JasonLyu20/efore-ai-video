# efore-ai-video

Efore 第一期产品视频项目。当前只涉及 IBUE48100、IBUE48200、ESmart-Li48160。

## 当前安排

更新日期：2026-11-05。团队共 5 人，暂按无人具备成熟后期能力安排；第一期不依赖外包，也不安排专业摄影、复杂合成或从零三维建模。

**采用“AI 短镜头＋基础剪辑”，产品图和已有准确素材作为替代。先用现有素材做一条 15 秒试剪，通过后才开展少量付费生成。** 华为 SmartLi 3.0 用于参考暗色背景、特写和慢速运动，不承诺同等制作水平，也不认定其由 AI 制作。

原三款产品、60–90 秒主片及三条 15 秒短片的交付目标保留。试剪是前置验证，不能代替整片验收。旧版 18 个工作日、112–168 人时和约 5,300 元基准预算不再作为当前执行承诺；正式工期和总预算在样片后重新确定。

## 协作方式

每项任务指定一位牵头人；成员姓名、截止日和实际投入由团队填写。文档和提示词存 GitHub，视频及源工程存团队共享盘并登记路径。状态按“待开始、进行中、待评审、已完成”记录，缺少资料或前置验证时标为阻塞。只根据实物产出和确认记录更新完成状态。

每个独立镜头使用 Shot ID，同一素材在短片、语言和编码版本中复用时不重复计费。参数、认证及安装方式均以具体型号资料为准。
