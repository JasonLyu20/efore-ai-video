## 1. 选型建议与使用边界

**使用场景**：产品展厅视频：优先外观真实、镜头一致与静音可理解；生成成本不代表成片总成本。

**如何使用**：先读总表，再看每项依据与价格档位；分数接近时不能判定实际优劣。预评分用于挑选 POC，不是采购验收。

**首批建议**：Seedance 2.0、Kling 3.0 Omni、MiniMax H3 做同素材对照；若 4K 直出优先，再加入 Vidu Q4 Preview。

**候选升级**：Seedance 2.5 与 Kling 4.0 主要验证复杂参考、编辑和长镜头是否减少返工；不因版本更新自动判胜。

**价格可比边界**：以 1080p 为主；H3 为 2K、Gen-4.5 为 720p、Q4 为 4K。主表比较选定生产档位，并非同画质性价比排名。

**待核验事项**：Q3 Pro 价格来自官方检索快照；Kling 4 的 4K 开放情况、账号地区/额度及最终商用条款，进入 POC 前核验。

**项目硬门槛**：Logo、端子、孔位、尺寸与参数不能漂移；不合格镜头即使总分高也不采用。参数文字建议由剪辑层叠加。

**原有预算关系**：本表只比较模型生成费，不能直接替代原费用方案；应在 POC 得到可用率后，再估返工、超分、配音和剪辑工时。

### 评分标准

**画质：细节 / 材质 / 光影 / 交付清晰度**

- 高分参考：8–9：较强公开证据和可用输出规格；10 需本项目稳定达到目标
- 低分或限制：清晰度不足、材质失真、无法达到交付规格
- 所需证据：官方规格 + 样片证据
- 本版处理：参考整体榜与规格作预估；不以分辨率替代画质。

**一致性：产品结构 / 主体 / 镜头连续**

- 高分参考：8–9：多参考、关键帧/编辑控制较充分
- 低分或限制：主体漂移；Logo、孔位和端子错误为硬失败
- 所需证据：同素材多次生成 + 逐帧检查
- 本版处理：控制能力是预评分依据，不是已证明的保持率。

**流畅度：抖动 / 闪烁 / 运镜 / 物理连续**

- 高分参考：8–9：运动与镜头控制有较强资料支持
- 低分或限制：跳帧、融化、运动不连续；高帧率不自动高分
- 所需证据：真实样片连续播放与逐帧回看
- 本版处理：整体榜仅作旁证，不制造维度测试数据。

**音画：原生声音 / 动作同步 / 台词**

- 高分参考：8–9：原生音画与声音控制较完整
- 低分或限制：0：无原生音频；需要另行后期制作
- 所需证据：同一镜头含音频样片
- 本版处理：此项仅评价模型原生音画，不评价整个编辑平台。

**成本：所选档位的 5 秒等效生成费**

- 高分参考：便宜得分高；使用下面统一阈值
- 低分或限制：不含重试、输入视频、人工等项目总成本
- 所需证据：同日期、同平台、同档位报价
- 本版处理：由成本表公式计算，阈值由团队调整。

**总分：加权结果 / 满分 100**

- 高分参考：单项 × 权重求和，再按权重合计归一
- 低分或限制：不能覆盖结构硬失败；近分不可判定胜负
- 所需证据：主表权重 + 五项分数
- 本版处理：公式自动计算；默认 30/30/20/5/15。

## 6. 下一步：同题样片验证与预算校准

**统一试验**：同一授权产品图、同一 16:9 构图、相同镜头目标；优先各平台 1080p。仅支持不同档位的模型单独分组，勿混为同规格测试。

**最小样片组**：每个候选 3 类镜头：正面慢推、约 30° 小幅环绕、产品与机房结合；每类至少 3 次独立尝试，完整保留失败样本。

**评分与淘汰**：至少两人盲评 0–10 分并记录原因；Logo/端子/孔位错误为硬失败。先淘汰结构错误，再比较画质、运动与费用。

**正式替换**：POC 后用实测评分替换主表 B–E；成本改用总生成支出 ÷ 合格视频秒数 × 5，并重新检查是否使用相同规格。

先完成小额样片验证，记录每次生成花费、合格秒数、返工原因与人工处理时间，再冻结工具组合和正式预算。项目中的需求分析、分镜和交付验收仍是独立环节，模型总分不能替代产品负责人对真实结构的确认。
